## The agent stack

What runs our fleet of Claude Code and Codex agents every day.

| Repo | What it does |
|---|---|
| [siso-agent-stack](https://github.com/siso-os/siso-agent-stack) | One version-pinned stack: skills, hooks, playbooks, profiles and runtime, installed together |
| [siso-agent-hooks](https://github.com/siso-os/siso-agent-hooks) | Lifecycle hooks for Claude Code and Codex: state, checkpoints and context guards, verified on install |
| [siso-agent-runtime](https://github.com/siso-os/siso-agent-runtime) | A provider-neutral shell for coding agents: configuration, composed profiles and context budgets |
| [jev-agent-skills](https://github.com/siso-os/jev-agent-skills) | A conservative second opinion for your agent: intent, completion, routing and browser judgment |
| [siso-session-intelligence](https://github.com/siso-os/siso-session-intelligence) | Turns session files into redacted, evidence-backed lessons your agents learn from |
| [siso-agent-playbook-public](https://github.com/siso-os/siso-agent-playbook-public) | How to run a fleet of agents under a budget: repeatable multi-agent scenarios |
| [siso-project-os](https://github.com/siso-os/siso-project-os) | An agent-first operating system for one project: tasks, a docs spine and UI campaigns |
| [siso-agent-integrations](https://github.com/siso-os/siso-agent-integrations) | Experimental adapters around the stack, each with a path to promotion |

## Research and the Great Library

Agents reading the world in the open. More at [sisolabs.space/research](https://www.sisolabs.space/research/) and
[the Great Library](https://www.sisolabs.space/great-library/).

| Repo | What it does |
|---|---|
| [siso-librarian](https://github.com/siso-os/siso-librarian) | The standing agent that keeps the Great Library growing, tidy and true |
| [siso-people-graph](https://github.com/siso-os/siso-people-graph) | One graph of the people who made things, across books, GitHub, papers and talks |
| [siso-book-library](https://github.com/siso-os/siso-book-library) | A queryable index over the world's public-domain books |
| [siso-evidence-engines](https://github.com/siso-os/siso-evidence-engines) | Source-grounded engines that turn reading into knowledge, principles and ideas |

| [siso-unsolveable-mathematics](https://github.com/siso-os/siso-unsolveable-mathematics) | Agents working open Erdős problems in the open |
