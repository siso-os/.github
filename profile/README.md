## What ships here

| | |
|---|---|
| **[Agent Base](https://github.com/siso-os/agent-base)** | The desktop app we run our agents from: every agent's chat, its tasks and a built-in browser in one window. |
| **[Voice](https://github.com/siso-os/siso-voice)** | Talk to your agents: dictation and spoken replies, on your own Groq key. Plugs into Agent Base with one command. |
| **[UI Hub](https://github.com/siso-os/siso-ui-hub)** | Every UI library we can find, previewed side by side, so agents build from the best components. Browse it at [hub.sisolabs.space](https://hub.sisolabs.space). |
| **[Skills Hub](https://github.com/siso-os/siso-skills-hub)** | Find, install and write skills for Claude Code and Codex. |
| **[Great Library](https://github.com/siso-os/great-library-of-siso)** | A public registry of what we built and studied, with releases, snapshots and the evidence for each. |

Each project gets its own repo here, with a preview video at the top of its README. Everything is MIT licensed.
Use it, fork it, make it better than ours.
