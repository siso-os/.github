## What ships here

| | |
|---|---|
| **Agent Base** | The desktop app we run our agents from: every agent's chat, its tasks and a built-in browser in one window. |
| **Voice** | Talk to your agents: dictation and spoken replies, on your own Groq key. Plugs into Agent Base with one command. |
| **UI Hub** | Every UI library we can find, previewed side by side, so agents build from the best components. |
| **Skills Hub** | Find, install and write skills for Claude Code and Codex. |

Each project gets its own repo here, with a preview video at the top of its README. Everything is MIT licensed.
Use it, fork it, make it better than ours.
